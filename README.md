# 抖音个人总结

这是一个完全本地、隐私优先的抖音个人记录工具。它通过独立浏览器读取本人账号当前可见的观看历史、点赞列表和收藏列表，再基于已有样本生成个人总结。

不使用抖音开放平台、外部 AI、Coze 或私有接口签名。标题、作者、封面、Cookie 和本地总结都不会发送到外部分析服务。

## 当前流程

1. 双击项目根目录中的 `抖音年度回顾.app`。这个旧文件名暂时保留，打开后会在后台启动本地采集器和 Web 页面，无需终端或配对码。
2. 首次使用时，在打开的独立浏览器中登录自己的抖音账号。
3. 在“数据源”点击“读取样本”。采集器会自动依次定位观看历史、点赞和收藏三个主页面。
4. 每个页面最多保留当前读取到的 50 条唯一记录。页面不足 50 条也会直接完成，不要求读取完整账号历史。
5. “总结”页面立即使用当前样本生成封面和 8 张全屏卡片，继续展示数量、作息、月份、常见创作者、显式话题、音乐、时长、列表交集和代表内容。

个人总结不需要先选择年份，也不要求记录具有行为时间。没有日期的记录仍会参与当前样本总结；应用不会用发布时间或采集时间伪造观看、点赞或收藏时间。

## 为什么还会滚动页面

抖音网页接口由抖音自己的页面脚本携带当前登录状态和签名发起。采集器只监听这些网页响应，不直接伪造 Cookie、`a_bogus`、`X-Bogus` 或其他私有签名。

因此自动同步需要在正确列表的真实可滚动区域中滚动，触发网页加载下一批数据。达到 50 条后立即停止；如果当前页面只返回更少记录，也会使用现有样本完成总结。

## macOS 一键启动

- 保持 `.app` 与本项目在同一目录，不要单独移到“应用程序”。
- 首次打开时允许访问“文稿”文件夹。
- 浏览器刷新后如需重新连接，再次双击 `.app`。
- 从 Dock 退出该应用会停止它启动的本地服务。

修改启动脚本后可重新生成应用：

```bash
npm run app:mac
```

## 开发方式

安装依赖并分别启动采集器与 Web 页面：

```bash
npm install
npm run collector
```

另开一个终端：

```bash
npm run web
```

打开 `http://localhost:8081`，在“数据源”填写采集器显示的 8 位一次性配对码。连接只读取现有本地快照；只有点击手动监听、读取样本或换账号时才会打开独立浏览器。

## 采集方式

- **自动同步**：依次定位观看历史、点赞和收藏三个主页面，每类最多保留 50 条。读取到当前页面样本即可完成，不再遍历全部收藏夹或追求完整分页。
- **手动监听**：打开独立浏览器后，由你自行浏览页面。采集器只保存监听期间实际出现的受支持网页响应，不限制为自动同步的 50 条样本。
- **换账号**：清除独立浏览器中的抖音会话和本地记录，然后等待你登录另一个账号。
- **文件导入**：JSON / ZIP 仍作为备用数据源。总结时每类使用前 50 条当前记录。

自动同步不会绕过验证码或安全提示。抖音页面结构或响应格式变化时会返回明确错误，不会把无法读取误报为空列表。

## 本地接口与隐私

- 本地服务默认监听 `127.0.0.1:4765`。
- `/v1/health` 用于健康检查，`/v1/pair` 使用一次性配对码，`/v1/sync` 启动自动同步。
- 12 小时会话 Token 只保存在应用内存和请求头中，不进入 URL 或本地存储。
- 独立浏览器配置保存在 `.local-data/browser-profile/`。
- 归一化记录保存在 `.local-data/records.json`。
- 原始响应、请求头、Cookie、签名和完整诊断 URL 不会写入记录文件。

App 中的“清除”只删除本地归一化记录，不会修改抖音账号里的观看、点赞或收藏状态。

## 手机连接

电脑和手机需位于同一可信局域网。电脑端显式启用 LAN 模式：

```bash
npm run collector -- --lan
```

应用中把服务地址改为采集器显示的局域网地址，例如 `http://192.168.1.20:4765`。Web 页面从局域网访问时还需传入实际页面来源：

```bash
npm run collector -- --lan --origin http://192.168.1.20:8081
```

LAN 模式仍使用一次性配对码和内存会话，但流量是局域网 HTTP，只应在可信网络使用。

## 当前边界

- Web 端提供个人总结、记录和数据源页面；原生端暂时保留记录和数据源。
- 总结描述的是当前最多 150 条列表样本，不代表完整账号历史，也不做心理诊断。
- 仅使用记录中的显式作者、话题、音乐、时长和平台互动字段，不调用外部 AI 推测兴趣。
- 暂不包含直播或影视综历史、收藏夹深度遍历、截图分享、PNG / PDF 导出。
