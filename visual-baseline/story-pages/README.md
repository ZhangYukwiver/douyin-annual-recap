# 故事页视觉基线

这 3 张 PNG 是项目故事页的原始静态预览基线，按页码对应：

- `pages-01-04.png`：第 01–04 页
- `pages-05-08.png`：第 05–08 页
- `pages-09-12.png`：第 09–12 页

文件保持原始 1536×1024 RGB 像素，不做压缩、缩放或重采样。逐像素比对时，现有页面需要使用相同的视口尺寸、设备像素比、浏览器缩放、字体和数据状态。

Web 故事页使用 `src/components/workspace/assets/reference/pages/page-*-hi.png` 的逐页 2×资源，按真实页面边界显示；第 09–12 页会排除原图中的白色分隔带，因此其显示宽度为 760/761 像素，高度为 505 像素。每页在四宫格中的精确源矩形记录于 `manifest.json`，应用内副本与原始四宫格基线同时保留，便于回溯和逐像素比对。
