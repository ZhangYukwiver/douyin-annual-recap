# 内容年志 · 即梦图片资产设计稿

目标：把 `prototype/story-entry.html` 与 `prototype/story-draft_副本.html` 里现在用 CSS/SVG 画的天空、云、封面替换成即梦生成的手绘图。星阵（数据动效）与飞鸟仍用 SVG，不在生成范围。

## 统一画风（所有提示词共用的后缀）

> 手绘厚涂油画质感，可见笔触与颜料颗粒，电影级色彩分级，柔和空气透视，画面无文字、无水印、无 logo、无边框、无人物，构图留白。

风格来源（只取这两处）：golden-portal 参考卡的油画金空（赭金厚云 × 群青天），refero GIC 的手绘暮色城市插画。

页面色板对齐（提示词里用文字描述，不写色号）：羊皮纸 #fefffc / 唯一蓝 #41a1cf / 群青 #2f5480 / 赭金 #d29a4e / 紫暮 #907a9c / 玫 #d8ac96 / 墨夜 #0e1420 / 余烬 #612a26。

## 生成与落地

1. 先只生成 S0 看风格是否对；不对就改后缀再批量。
2. 命名落到 `jimeng/story-images/`：`sky-s0-dawn.jpg`、`entry-night.jpg`、`sky-s1-morning.jpg`、`sky-s2-dusk.jpg`、`sky-s3-night.jpg`、`sky-s4-ember.jpg`、`cover-01…05.jpg`、`wash-dawn/dusk/night/ember.png`、`avatar-creator/friend/group.jpg`。
3. 接入：故事页 `.s0–.s4` 与入口页 `#sky` 改成 `background-image: url(...)` 铺满（原渐变保留做加载兜底，云团 blob 去掉）；`.card-cover.c1–c4` 与分享卡 `.sc` 换成图片；水彩晕斑用 `mix-blend-mode: multiply` 叠在纸面下。
4. 生成完成后逐屏截图核对：天空窗文字对比度（S1 要够亮、S0/S2/S3/S4 要够暗）、五态 crossfade 是否跳。


## 生成结果（2026-09-02）

- 已生成并接入：`sky-s0-dawn`（文生图主图，8 积分）、`sky-s1-morning` / `sky-s2-dusk` / `sky-s3-night` / `sky-s4-ember` / `entry-night`（全部以 S0 为参考图只改光色，各 8 积分）。每张 2560×1440，PNG 为母版、JPG 供页面用。水印：账号已开「去除水印」设置后官方下载即无「AI生成」标；构图仍留了左上角空白以备裁切。
- 不生成：C1–C5 内容卡封面、分享卡封面、A1–A3 头像——真实产品里来自采集字段 `coverUrl` / `share.coverUrl` / `authorAvatarUrl` / `senderAvatarUrl`，设计稿里保持占位。W1–W4 水彩晕斑用 CSS 径向渐变即可，不生成。
- 连贯性方法：文生图只出一张主图；其余全部用「参考图 + 只改时间与光色」派生，云形、层次、笔触完全一致，crossfade 不跳。
- 入口页混色图定稿：`entry-mix.jpg` = 五张派生图按固定平滑权重场混合（云形与 S0 一致），探照灯只透这一张。即梦直出的两版（`entry-mix-v1/v2-reshaped`）会重画云形，弃用留档。
